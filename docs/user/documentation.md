# lognav documentation

lognav is a terminal UI for parallel IBM Cloud Logs searches, jq filtering,
snapshots, and optional 1Password credentials.

## Start here

- [Overview and quick start](../README.md)
- Commands: `lognav --help`, then `lognav <command> --help`
- Configuration: `lognav config describe`, `lognav config get`, and `lognav config show`
- Embedded pages: `lognav docs <topic> --print` or `lognav docs --greppable | rg 'text'`
- Agent onboarding: `lognav instruct`
