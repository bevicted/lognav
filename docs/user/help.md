# Help and community

Use these local help paths first:

- `lognav --help` for commands and global options
- `lognav <command> --help` for command-specific behavior
- `lognav config describe` for configuration fields and defaults
- `lognav docs <topic> --print` for one embedded documentation page
- `lognav docs --greppable | rg 'text'` to search embedded pages
- `?` in the TUI for context-sensitive keybindings

Questions, bug reports, feature requests, and discussion belong in the
[lognav repository](https://github.com/bevicted/lognav).
